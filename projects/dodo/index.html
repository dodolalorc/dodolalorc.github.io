    Dodo 是一个正在开发中的个人生活记录 App，面向 iOS 和 Android。它希望把日程、待办、计划、打卡、记账以及日记 / 备忘放进同一个日常使用的空间，让安排事情、记录过程和回顾生活能够自然衔接。

    目前项目处于开发与个人测试阶段。这篇文章先记录产品企划与设计方向，具体功能和迭代顺序会随着实际使用继续调整，不代表正式版本的功能承诺。

    项目源码：github.com/dodolalorc/dodo

    为什么做这个项目

    生活中的记录往往彼此相关，却散落在不同工具里。准备一次旅行，需要安排行程、整理待办、记录花费；制定一个读书或运动计划，需要拆分行动、持续打卡，再回顾执行情况。

    Dodo 想把这些记录放到一起：从一个计划出发，找到相关的行动和支出；从一次打卡或一笔账单回到它所属的目标。每个模块可以独立使用，也能在需要时建立联系。

    产品首先服务于一个人的日常生活，以中文体验和手机操作为中心。默认不需要账号，也不预设社交关系或多人协作，让打开、记录、离开的过程尽量轻便。

    一个围绕时间展开的首页

    首页以本地时间为中心，周围采用环形模块入口，默认呈现「日程、记账、计划、打卡」。时间与常用工具处在同一个视野里，打开后可以直接进入当下要做的事情。

    不同人的生活重心并不一样，因此首页也希望保留调整空间：选择显示哪些模块、修改名称、调整顺序，并在入口较多时分页展示。待办等工具既可以从生活工具页进入，也可以加入首页。

    整体视觉沿用暖灰背景、绿色强调色和中文系统字体，以清晰的文字、留白和信息分组建立层级。环形入口是这个项目的辨识点，后续打磨会重点关注标签可读性、点击便利性和不同屏幕上的表现。

    计划中的生活工具

    以下是产品希望覆盖的方向，包含正在实现和后续规划的内容。

    模块希望解决的问题
    日程管理有明确日期或时间的安排，逐步补齐日历与提醒体验
    待办快速记下要做的事，管理完成状态，承接计划中的具体行动
    计划 / 旅行组织长期目标、旅行预算和相关记录，后续扩展行程与阶段任务
    打卡记录单次完成、次数或时长，通过周视图与热力图回顾习惯
    记账与资金记录收支、账户与转账，查看预算，并把支出关联到具体计划
    日记 / 备忘留下文字记录，为日常想法和生活片段提供保存入口

    让记录之间建立联系

    模块联动是 Dodo 的一个重点方向。例如，一次旅行可以有自己的预算，实际花费关联到同一个计划；一个长期目标可以关联打卡项目与待办，方便从不同角度查看进展。

    这些联系应当保持清楚：关联账单时复用原有记录，避免重复记账；打卡达标与待办完成各自保留明确含义，不在用户不知情的情况下替另一项操作做决定。解除关联也应尽量保留原本有价值的历史记录。

    希望最终形成的体验是，记录一次之后，可以在相关场景中找到它，同时仍然理解每条记录来自哪里、代表什么。

    本地优先与数据可携带

    Dodo 以设备本地存储为基础，默认无账号、无后端，优先完成离线个人记录的基本体验。

    长期使用还需要可靠的数据出口。因此，带格式版本的导出与导入、数据校验和恢复流程，是后续的重要工作。设备间同步则留待实际需求明确后再考虑。

    当前尚未完成自动备份与同步，数据只属于当前安装，现阶段仍以测试数据为主。数据可携带与恢复能力完善后，才适合进一步承担长期生活记录。

    技术方向

    项目使用 React Native、Expo 和 TypeScript 构建两端应用，Expo Router 组织页面与导航，SQLite 保存本地业务数据。

    日程、待办、打卡和记账按各自业务组织，通过稳定的记录 ID 建立关系。数据库变更采用逐版本迁移，为后续增加功能和保留历史数据打基础。

    技术选择围绕实际记录需求展开：账目需要准确的金额计算，日程和打卡需要清楚地区分日期、具体时刻与时区，跨模块操作需要保持数据一致。这些基础会和界面体验一起逐步完善。

    后续迭代方向

    当前已经围绕首页自定义、待办、打卡、记账和计划预算展开实现，整体仍在持续开发中。接下来主要关注：

    1. 完善已有记录流程，在 iOS / Android 真机上检查操作、布局和异常状态。
    2. 补齐数据导出、导入与恢复能力，为长期使用做好准备。
    3. 逐步完善日程、日记 / 备忘、搜索与本地提醒。
    4. 扩展旅行行程和阶段任务，让计划与日常行动更紧密地连接。
    5. 根据实际需要探索系统分享、设备间同步和正式安装分发。

    这份企划会随着开发与日常试用继续更新。Dodo 希望成为一个可以每天打开、顺手留下一点记录，也能在之后找回生活脉络的工具。
